<h2>Agenda tugas</h2>

untuk membantu siswa yang sering lupa soal pengumpulan tugas dan pengingat adanya pengambilan nilai, yang digunakan untuk siswa SMK untuk menjadi siswa yang lebih disiplin serta membantu siswa bisa mencatat, memantau dan menyelesaikan tugas sekolah
<br>Fitur utama yang diperkenalkan ada tambah tugas, lihat daftar tugas, ubah tugas, hapus tugas, tandai tugas selesai, dan pencarian tugas
<p>untuk berkas saat ini ingin diarahkan ke dalam file JSON dibaca saat aplikasi dibuka dan disimpan setiap ada perubahan</p>
<p>Cara menjalankannya, seperti biasa dijalankan dan akan disediakan beberapa menu 1 2 3 4 5 6 dan 0 yang dimana masing masing ada fungsinya tersendiri</p>
<p>1. untuk tambah tugas, 2. untuk menampilkan tugas, 3. Mencari tugas, 4. Mengubah status tugas, 5. Menyimpan data, 6. menghapus tugas, 0. Keluar</p>
